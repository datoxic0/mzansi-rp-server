# Mzansi-ZA

A South African roleplay environment starter resource for MTA-style server architecture.

## Included systems
- Shared enums, config, and utility helpers
- Player persistence layer with SQLite-backed storage
- Banking deposit/withdraw operations
- MDT search skeleton
- Character registration flow
- HUD and CEF UI shell
- Job/faction enum support

## Notes
This structure is intentionally modular so it can be extended with South African vehicles, business scripts, factions, and map assets.
